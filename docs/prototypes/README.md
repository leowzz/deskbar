# 页面与组件交互原型

[workbench.html](workbench.html) 是自包含的 HTML 文件，可直接打开。也可在仓库根目录运行 `make prototype`，访问终端提示的本机 URL。

原型支持页面横滑、页签跳转、新建与重命名、页面排序与删除、重复组件、隐藏、拖动缩放、参数调整、跨页移动、临时铺满、撤销与取消。

会话组件的目标宽高决定内部行列；入口组件独立设置图标大小与横纵间距。正常状态横滑切页，内容上下滚动；编辑状态拖动把手调整组件。

数据与动作均为示例，只保存在内存，刷新后恢复初始页面。它不包含真实设备连接、来源选择、正式持久化或 Android 安全区实现。浏览器中的 CSS px 用于演示，正式 Android 实现使用 dp / sp。

前期浏览器验证覆盖横滑防误触、实例参数独立、跨页移动、取消恢复、大图标尺寸和窄窗口适配；这些证据不代表 Android 功能已实现。详细目标见 [工作台设计](../workbench.md)。


## UI 方向探索

### 已确认配色与探索原型

[四套配色对比](color-study.prototype.html) 是 2026-10-16 新一轮独立视觉原型，使用同一布局比较配色。已确认 **01 铂银为默认浅色、02 墨黑为暗色**，完整规范记录在 [DESIGN.md](../../DESIGN.md)，正式 App 尚未接入。

| 配色 | 方向 |
| --- | --- |
| 01 · 铂银 | 已选为默认浅色：冷白、石墨灰与少量钢蓝 |
| 02 · 墨黑 | 已选为暗色：中性深灰与柔白 |
| 03 · 暖纸 | 未采用，保留为探索历史 |
| 04 · 雾蓝 | 未采用，保留为探索历史 |

支持四套并排对比、单套细看，以及电脑连接助手、横屏工作台和手机竖屏预览。单套模式可用左右方向键切换，并查看主色值与状态配色；「离线效果」展示缓存提示与不可执行的打开操作。开关和喜欢标记只保存在当前页面内存，不改变真实设备权限；喜欢标记不会发送给聊天，刷新后清除。

可直接打开文件，或运行 `make prototype` 后访问 `/prototypes/color-study.prototype.html`。URL 参数 `palette=silver/graphite/paper/slate`、`surface=helper/wide/phone`、`mode=compare/detail` 和 `offline=1` 保留预览条件。四套原型保留便于回看；设计结论以根目录 `DESIGN.md` 为准，原型中的临时喜欢标记不更改该结论。

### 上一轮布局与配色

[三套双端 UI 方案](ui-directions.prototype.html) 保留上一轮工作台和连接助手的视觉探索，不作为当前配色实现依据，也不修改正式应用。可直接打开，或运行 `make prototype` 后访问 `/prototypes/ui-directions.prototype.html`。

| 方案 | 内容主次 |
| --- | --- |
| A · 安静工作台 | 会话为主，额度与常用入口在侧边；浅色、轻量，作为默认方向候选 |
| B · 专注屏 | 当前任务为主，近期会话在侧边，入口收到底部；适合常驻副屏 |
| C · 快捷桌面 | 应用与网址入口为主，会话作为精简列表；暖灰、轻触感 |

底部切换方案，顶部切换横屏、手机竖屏和电脑连接助手；也可使用键盘左右键。URL 的 `variant=A/B/C` 和 `surface=wide/phone/helper` 可保留当前预览。提供离线状态、会话点击和本地开关示意，数据与动作均为样例，不连接真实设备、不保存设置。三个方案表达不同信息层级，不代表给正式工作台增加固定页面类型。

A 方案另提供 8 组浅色配色缩略对比，布局保持一致；通过 `palette=01` 至 `palette=08` 记录当前选择，可同时查看完整的横屏、手机和电脑端效果。
