# 页面与可选组件

状态：电脑负责页面和组件编辑、自动更新；Android 负责展示与操作。2026-10-20。

工作台由有序页面组成，每页可添加任意组件，同类组件可以重复添加。组件拥有独立的来源绑定、横竖屏摆放与显示参数。初始提供「总览」「任务」「应用」三页；默认总览为顶部状态栏、左侧额度、右侧两列六条会话、底部居中快捷入口（间隙 8 px）。会话超过六条后可上滑继续浏览。竖屏按状态栏、额度、会话、快捷入口排列。该默认布局用于尚未配置布局的设备，已有自定义布局保持原样。新页面为空白，至少保留一页。页面列表「＋ → 添加横屏总览」复用默认总览，保留原页面，整次添加可撤销。

## 双端分工

| 电脑端「屏幕编辑」 | Android 工作台 |
| --- | --- |
| 选择设备，管理页面、组件与来源 | 接收电脑更新的布局 |
| 新建、改名、排序、删除页面 | 左右滑动或键盘切页 |
| 添加、隐藏、恢复、移动、缩放组件 | 会话上下滚动、入口横向滚动，打开已授权内容 |
| 选择内容、会话列数与每屏数量、入口名称、对齐与居中间隙 | 主题、全屏显示、锁定旋转、重连、断开连接 |
| 预览、布局调试、撤销 / 重做、自动更新 | 离线查看上次布局和数据，禁止远程动作 |

移动端右上角的「设置」和长按空白 / 非交互内容均打开基础设置，不进入编辑。全屏后设置入口仍保留。页面和组件的编辑入口只出现在电脑端。

## 编辑与实时预览

在电脑的「屏幕编辑」通过横向平铺的卡片选择设备，卡片显示设备名称和设备 ID 前 8 位摘要，连接与布局同步状态位于各自卡片右下角，编辑提示也收在当前卡片内；悬浮可查看完整标识，窄窗口自动换行，编辑期间禁止切换。直接点击画布或左侧列表中的组件编辑属性，无需切换编辑模式。左侧常驻页面与本页组件：点击切页、拖动页面握柄排序，页面菜单重命名或删除；组件旁的眼睛按钮隐藏或恢复。顶部「添加组件」直接选择类型，支持重复添加；工具栏提供整理、撤销、重做和完成。每次变更停止操作约 450ms 后自动更新本机布局并下发设备，编辑期间可以继续修改；更新失败保留当前改动，并在后续变更或完成时重试。

编辑器与 Android 共用 Flutter 的 `WorkbenchCanvas`、`WorkbenchWidgetBody` 和布局模型。预览持续读取该设备的授权快照；不会用电脑的全量数据冒充设备可见内容，也不会执行打开动作。React 外壳仅负责设备选择、同源消息桥接和 Tauri 持久化调用。

预览直接使用设备上报的工作台可用宽高（已排除系统安全区和 App 顶栏）、主题和当前页面；电脑端会按设备 ID 保存最近一次宽高，设备暂时离线时继续按该尺寸编辑，首次未上报时才使用 1280 × 720 dp 作为占位。编辑器默认跟随设备当前横竖屏；需要编辑另一套摆放时可手动选择横屏或竖屏，再选择「跟随设备」恢复自动跟随。工具栏不展示设备尺寸或字号信息。横竖屏使用同一台设备的长边和短边，不区分固定分辨率，也不提供自定义宽高。预览在电脑窗口中等比缩放，布局仍按设备 dp 计算；「布局调试」默认关闭，可关闭；「原始尺寸」仍可滚动画布查看调试标注。预览是同源数据渲染，不是设备截图或视频，组件内部滚动位置不镜像。

编辑器按电脑窗口宽度排布，设备旋转只改变中央画布和当前编辑的横 / 竖屏摆放。编辑区域宽度达到 1000 px 时，左侧固定 220 px 页面与组件列表，右侧固定 300 px 属性，中间画布等比适配；700–999 px 时，右侧以「页面与组件 / 属性」切换；更窄窗口在画布下方切换面板。选中前后保留画布区域，面板不覆盖预览。组件不显示编辑标题条或设置浮窗，选中后显示边框及边缘缩放握柄，整个内容区域都可拖动。切换方向保留选择与当前改动，两种方向独立摆放；属性使用电脑字号，设备字号仅影响预览。属性可直接输入位置、宽高和显示参数，数字输入框右侧提供加一 / 减一按钮；位置与尺寸以当前方向网格为单位，Enter 或离开输入框提交，无效值或空间不足时恢复原值。「布局调试」用淡色透明填充和小边框标出组件区域，并在会话卡片、快捷入口单元、用量内容区及用量内部 item 标注边界和实际尺寸；这些标注默认隐藏，鼠标悬浮组件或内部 item 时才显示对应边界和尺寸。调整组件宽高或拖动组件时，当前组件显示尺寸，当前页其他可见组件只显示外边框，帮助判断可用范围。调试仅影响电脑界面，不写入布局或下发设备。

## 组件自主适配

画布只负责组件的外部位置与区域尺寸；内部布局由组件根据实际可用宽高、内容与系统字号决定。电脑预览和 Android 使用同一实现。缩放组件时不需要再调整内部卡片宽高、字号、密度或图标尺寸；快捷入口的居中间隙可按偏好设置。

| 组件 | 常用配置 | 自动适配 |
| --- | --- | --- |
| 会话 | 列数、每屏会话数 | 卡片均分区域；窄屏减少列数；根据空间显示标题、状态、仓库、分支、模型、推理强度和更新时间 |
| 额度 / API 用量 | 显示内容、资源窗口 | 宽条横排，窄侧栏优先上方主值 / 下方两项详情，极窄高栏竖排，矮区域保留主值与摘要 |
| 快捷入口 | 显示名称、对齐方式、居中间隙 | 单行横向排列；图标按高度适配，宽度不足时横向滚动；低高度优先显示图标 |
| 顶部状态栏 | 左侧名称、时间、连接、主题与设置入口 | 宽屏单行，窄屏按高度换行，低高度简化时间和连接文字 |

「高级设置」只保留名称、网格位置与尺寸、可见性及来源。移动页面与删除入口始终可见，所有修改仍可撤销。旧布局中的内部尺寸参数继续兼容读取和保存，但不再控制渲染，也不在面板中暴露；内容、绑定、摆放和可见性保留。

## 编辑行为

| 操作 | 规则 |
| --- | --- |
| 移动 / 缩放 | 组件整个区域拖动移动，选中后左右 / 下边缘与下角缩放；碰撞时其他组件就近让位，空间不足则保留原布局 |
| 隐藏 / 恢复 | 保留实例与原位置；恢复冲突时提示先整理 |
| 整理本页 | 只重排当前页、当前方向的可见组件 |
| 移到其他页 | 保留 ID、绑定与参数，两种方向均需有空间；整行状态栏自动预留顶部区域，必要时收拢下方组件，整次移动可撤销 |
| 删除页面 | 确认后删除页面及组件，当前改动中可撤销 |
| 自动更新 | 每次变更停止操作约 450ms 后原子更新所有页面并推送给对应设备；编辑期间可以继续修改，失败保留当前改动并在后续变更或完成时重试 |

画布或组件列表选中后，方向键移动一格，Shift + 方向键移动十格；Delete / Backspace 删除组件，Escape 取消选择。⌘ / Ctrl + Z 撤销，⌘ / Ctrl + Shift + Z 或 Ctrl + Y 重做。输入框保留文字编辑快捷键；完成会先提交当前数值输入并等待未完成的自动更新。

横屏使用 48 × 48 网格，竖屏使用 16 × 96 网格；分别记录摆放，实例参数共用。一次拖动和所有碰撞让位占用一条撤销记录。编辑中不能切换设备；切换电脑应用导航后保留当前改动。

移除当前设备会结束它的编辑会话；还有其他设备时自动选择下一台，全部移除时回到连接提示。重新配对使用新的设备 ID 和独立编辑状态，旧设备的加载、保存回复与尺寸缓存不会应用到新设备；同一设备的普通状态刷新仍保留正在编辑的内容。

电脑窗口隐藏或切到其他页面时暂停预览轮询，回到屏幕编辑后立即刷新，保留当前编辑状态与保存回复。同一设备在页面切换时复用预览实例，避免反复创建 Flutter 引擎。预览桥接只在可渲染的动画帧应用最新一份状态，避免后台渲染暂停时持续构造 Flutter 状态而积累内存。

预览内容未变化时，单纯的服务时间与设备心跳不重复触发 Flutter 更新；布局、共享许可、内容或在线状态变化仍会同步。

新建会话组件每屏默认 6 条，可设 1–40 条；已有布局保留原来的 `maxSessions` 值，缺少该字段的旧布局沿用 20。每屏数量只控制卡片高度，数据源返回的会话全部保留在同一个纵向列表中，超出当前屏幕的部分上滑继续查看，无翻页按钮和页码。刷新保留滚动位置，数据减少时自动收敛到有效范围。列数支持自动或 1–6 列，区域过窄时自动减少。卡片在可读范围内缩放，空间不足时保留至少 60 dp 卡片并滚动。标题始终保留，按可用空间展示仓库（缺失时用项目名）、分支、模型、推理强度与更新时间；紧凑卡片用状态点，长按 / 悬浮提示提供完整文字及具体更新时间。来源缺少的元数据不补造。

快捷入口支持配置 1–12 行，默认 1 行；按从左到右、从上到下排列。单页数量默认不限，所有入口放在一个网格中，宽度不足时保留图标大小并左右连续滚动。开启「限制单页数量」后可设 1–64 个，图标按行数、单页数量和组件区域自动适配；多余入口通过左右滑动逐页切换，最后一页只显示剩余入口，不增加滚动条或翻页按钮。实际入口不足一页时按已有数量排版。低高度隐藏名称，名称仍可通过提示与语义读取；空间不足以容纳所设行数时提示增加高度或减少行数。

新建组件默认隐藏名称、居中对齐，显示全部已授权入口。居中对齐时提供「图标间隙」滑条，范围 0–16 px（设备逻辑像素），默认 8；分页时区域不足会自动收紧间隙。其他对齐方式不显示滑条，切换对齐保留已设间隙。

入口网格溢出或有多页时，从网格内开始的横向拖动只移动入口，即使到达两端也不会切换工作台页面；触控板横滑与滚轮惯性遵循同一规则。网格外和组件上下留白仍可横滑切页，入口全部放得下且仅有一页时也可直接在网格内横滑切页。拖动不触发打开动作；电脑编辑预览仍由外层处理组件移动和缩放。

额度先扣除边距与状态提示，再按剩余区域排版，避免离线状态把重置时间挤出边界。宽条横排剩余额度、重置时间和倒计时；窄侧栏也优先保留上方主值、下方并排重置时间和剩余时间的三分布局，标签与数字随单元宽度缩小。仅极窄高栏分区竖排、很矮时显示主值与重置摘要。数字在各自区域内缩放。API 用量沿用相同规则，显示实际成本、Token 与 TPM；美元金额使用 `$` 前缀（如 `$12.34`），其他币种保留币种代码。离线、旧数据和过期窗口仍明确提示，完整详情可通过提示查看。

## 顶部状态栏与总览样式

「添加组件 → 顶部状态栏」可独立添加、移动、缩放和隐藏；名称左对齐，日期时间固定在状态栏中心，连接状态、主题切换和设置入口右对齐；窄屏空间不足时，时间居中换到下一行，低高度仅显示时分。左侧名称可自定义或留空，日期时间、秒数、连接状态、主题切换和设置入口分别开关。时间使用工作台本机时区，连接状态来自实际连接，不依赖会话或额度共享。点击主题按钮沿用 Android 本机保存；电脑编辑预览只展示按钮，不执行切换。状态栏提供设置入口时，不再叠加右上角悬浮设置按钮；关闭入口或隐藏组件后恢复悬浮按钮，长按基础设置入口仍保留。

向已有页面添加或移入整行状态栏时，横竖屏分别预留顶部空间：顶部已有空白时保持其他组件不动，否则向下移动，空间不足时按比例收拢高度，保留左右位置和配置。隐藏组件不参与收拢；如果任一方向无法保留有效尺寸，整次操作不生效，组件留在原页。非整行状态栏按普通组件寻找空白区域。

会话统一使用轻边框卡片，运行中采用状态色。额度窗口由资源选择决定，没有选择时显示第一个已授权窗口；重置后显示等待刷新。快捷入口缩成低高度区域时自动形成图标栏；横屏总览保留底部栏的轻分隔线。

## 配置与同步

布局结构见 [跨端布局样例](../protocol/layout.example.json)。数组顺序决定页面顺序，实例 ID 不随移动或改名变化。会话使用 `columns`（`auto` / 1–6）与 `maxSessions`（1–40，每屏数量）；快捷入口使用 `rows`（1–12，缺省或旧 `auto` 为 1 行）、`maxShortcuts`（0–64，缺省或 0 为不限，正数为单页数量）、`spacing`（0–16，仅居中时使用）、`labels` 与 `alignment`（`left` / `center` / `spaceEvenly` / `right`）；用量使用 `content` 与来源绑定；状态栏使用 `label`、`showClock`、`showConnection`、`showThemeButton`、`showSettingsButton`。旧的尺寸、密度、字号等字段继续接受但不参与内部布局；旧状态栏 `showSeconds` 偏好仍保留。完整组合见 [总览样例](../protocol/dashboard.example.json)。仍使用布局版本 3，更新双端才能获得一致的自动适配、连续滚动与入口分页行为；不迁移 Android 旧本机布局。

- Host 在每个设备记录中保存布局与独立的 `layout_revision`，和许可一起原子写入 `host.yaml`。
- 电脑保存携带预期布局版本，版本冲突拒绝覆盖。来源数据刷新不会造成布局保存冲突。
- 授权快照包含该设备自己的 `layout` 与 `layout_revision`；保存后 WSS 推送，重连接收最新完整快照。
- Android 不读写旧本机布局文件，布局随授权快照由 Keystore 加密缓存。离线可展示；明确撤权清除凭据和缓存。
- Android 切页保留当前运行页面；接收新布局时若当前页仍存在则保留，否则切到电脑配置的默认页。
- 设备每五秒及尺寸 / 页面变化后上报显示状态和已应用布局版本。电脑区分已更新、等待接收和离线；本机更新完成不等于设备已经接收。
- 显示报告不修改布局、不提升权限、不包含凭据或电脑路径。组件隐藏也不停止电脑任务或撤销共享。

## 实现边界与验证

`LayoutWorkspace` 管理不可变文档、当前编辑改动和撤销。电脑编辑入口为 `desktop_editor.dart`，构建为随 Tauri 打包的本地 Flutter Web 资源；CanvasKit、字体均本地打包，不引入独立服务。Android 主入口不启用编辑。旧 `LayoutRepository` 只用于已有编辑器存储测试，不再作为移动端生产配置来源。

两端组件使用本地 Noto Sans SC 字体，减少浏览器与 Android 的文字度量差异。实际系统渲染、安全区、触摸与生命周期仍需真机验收。检查范围与历史证据见 [跨端验证](../tests/README.md)；[HTML 原型](prototypes/workbench.html) 是旧交互探索，不代表当前双端分工。
