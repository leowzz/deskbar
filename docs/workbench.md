# 页面与可选组件

状态：电脑负责页面和组件编辑、保存；Android 负责展示与操作。2026-10-16。

工作台由有序页面组成，每页可添加任意组件，同类组件可以重复添加。组件拥有独立的来源绑定、横竖屏摆放与显示参数。初始提供「总览」「任务」「应用」三页，新页面为空白，至少保留一页。

## 双端分工

| 电脑端「屏幕编辑」 | Android 工作台 |
| --- | --- |
| 选择设备，管理页面、组件与来源 | 接收电脑保存的布局 |
| 新建、改名、排序、删除页面 | 左右滑动或键盘切页 |
| 添加、隐藏、恢复、移动、缩放组件 | 组件内容上下滚动，打开已授权会话与入口 |
| 调整卡片宽高、图标大小、间距、数量 | 主题、全屏显示、锁定旋转、重连、断开连接 |
| 预览、布局调试、撤销 / 重做、完成 / 取消 | 离线查看上次布局和数据，禁止远程动作 |

移动端右上角的「设置」和长按空白 / 非交互内容均打开基础设置，不进入编辑。全屏后设置入口仍保留。页面和组件的编辑入口只出现在电脑端。

## 编辑与实时预览

在电脑的「屏幕编辑」选择设备，直接点击预览中的组件打开属性表单，无需先切换编辑模式。页面菜单切换编辑对象，工具栏提供添加组件、组件列表、页面管理、整理、撤销和重做。

编辑器与 Android 共用 Flutter 的 `WorkbenchCanvas`、`WorkbenchWidgetBody` 和布局模型。预览持续读取该设备的授权快照；不会用电脑的全量数据冒充设备可见内容，也不会执行打开动作。React 外壳仅负责设备选择、同源消息桥接和 Tauri 保存调用。

「跟随设备」使用设备上报的工作台可用宽高（已排除系统安全区和 App 顶栏）、字号倍率、主题和当前页面。设备未上报时以 1280 × 720 dp 预览；离线时保留最后尺寸并标明离线。也可选择横屏、竖屏或输入自定义宽高；自定义尺寸仅改变电脑预览。预览在电脑窗口中等比缩放，布局仍按指定 dp 计算；可开启「原始尺寸」并滚动画布，查看较小文字和调试标注。预览是同源数据渲染，不是设备截图或视频，组件内部滚动位置不镜像。

编辑器分为顶部设备选择与基础操作、预览、属性表单三个区域，区域间以留白分隔，不使用包围编辑器的外框、预览边框或分隔线。组件不显示编辑标题条或设置浮窗。属性表单位于渲染区域外：预览为竖屏时固定在右侧，横屏时固定在下方并按可用宽度分列，判断依据是目标屏幕方向而非电脑窗口形状。面板区域在选择前后保持不变；选中组件显示边框及边缘缩放握柄，整个内容区域都可拖动。切换方向保留当前选择和草稿，使用该方向独立的组件摆放；表单按电脑字号显示，设备字号仅影响预览。「布局调试」叠加区域边界与实际尺寸，会话显示实际列数、卡片宽高和间距，快捷入口显示单元宽高、图标大小和横纵间距。调试仅影响电脑界面，不保存、不下发。

## 编辑行为

| 操作 | 规则 |
| --- | --- |
| 移动 / 缩放 | 组件整个区域拖动移动，选中后左右 / 下边缘与下角缩放；碰撞时其他组件就近让位，空间不足则保留原布局 |
| 隐藏 / 恢复 | 保留实例与原位置；恢复冲突时提示先整理 |
| 整理本页 | 只重排当前页、当前方向的可见组件 |
| 移到其他页 | 保留 ID、绑定与参数，两种方向均需有空间 |
| 删除页面 | 确认后删除页面及组件，草稿中可撤销 |
| 完成 | 原子保存所有页面，成功后推送给对应设备；失败保留草稿 |
| 取消 | 恢复本轮编辑前的全部页面 |

横屏使用 48 × 48 网格，竖屏使用 16 × 96 网格；分别保存摆放，实例参数共用。一次拖动和所有碰撞让位占用一条撤销记录。编辑中不能切换设备；切换电脑应用导航后保留草稿。

会话数量默认 20，可设 1–40。目标卡片宽度决定整数列数，卡片均分整行；完整行铺满开启时，实际高度均分可见高度，否则使用目标高度并内部滚动。系统大字号提高最小高度，不整体缩小文字。快捷入口保持设定图标尺寸，空间不足时提示在电脑调整组件。

## 配置与同步

布局结构见 [跨端布局样例](../protocol/layout.example.json)。数组顺序决定页面顺序，实例 ID 不随移动或改名变化。只接受当前布局版本，不迁移 Android 旧本机布局。

- Host 在每个设备记录中保存布局与独立的 `layout_revision`，和许可一起原子写入 `host.yaml`。
- 电脑保存携带预期布局版本，版本冲突拒绝覆盖。来源数据刷新不会造成布局保存冲突。
- 授权快照包含该设备自己的 `layout` 与 `layout_revision`；保存后 WSS 推送，重连接收最新完整快照。
- Android 不读写旧本机布局文件，布局随授权快照由 Keystore 加密缓存。离线可展示；明确撤权清除凭据和缓存。
- Android 切页保留当前运行页面；接收新布局时若当前页仍存在则保留，否则切到电脑配置的默认页。
- 设备每五秒及尺寸 / 页面变化后上报显示状态和已应用布局版本。电脑区分已同步、等待接收和离线；保存成功不等于设备已经接收。
- 显示报告不修改布局、不提升权限、不包含凭据或电脑路径。组件隐藏也不停止电脑任务或撤销共享。

## 实现边界与验证

`LayoutWorkspace` 管理不可变文档、全页面草稿和撤销。电脑编辑入口为 `desktop_editor.dart`，构建为随 Tauri 打包的本地 Flutter Web 资源；CanvasKit、字体均本地打包，不引入独立服务。Android 主入口不启用编辑。旧 `LayoutRepository` 只用于已有编辑器存储测试，不再作为移动端生产配置来源。

两端组件使用本地 Noto Sans SC 字体，减少浏览器与 Android 的文字度量差异。实际系统渲染、安全区、触摸与生命周期仍需真机验收。检查范围与历史证据见 [跨端验证](../tests/README.md)；[HTML 原型](prototypes/workbench.html) 是旧交互探索，不代表当前双端分工。
