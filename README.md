# Desklet

Desklet 把 Android 屏幕变成电脑旁的工作台。电脑安装 **Desklet 连接助手**（Agent），Android 安装 **Desklet 工作台**，通过局域网配对连接。目标是显示会话、额度与 API 用量，并打开已授权的会话和快捷入口。

**当前阶段：单电脑工作台。** 已支持加密配对、逐设备共享 Codex 会话 / 额度和 Sub2API 用量、网页 / 应用入口，以及手机点击回到电脑打开。Android 可自由组合多页与重复组件，编辑布局和显示参数并在本机保存；断线可继续编辑和查看上次数据。双端默认使用铂银，支持独立保存墨黑主题。

短配对码依赖的 PAKE、多网卡与网络变化、物理设备适配、签名安装与发布仍在开发计划中。当前构建是开发版本。

## 产品范围

- 一个桌面安装包，加一个 Android 安装包；无需部署 Core、MQTT Broker 或独立服务器。
- 会话、额度、API 用量和快捷入口均作为可选组件，支持同类组件重复添加。
- 页面自由组合组件，左右横滑切页；每个实例独立设置位置、区域尺寸和显示参数。
- Session 卡片可调整目标宽高与间距；快捷入口可调整图标大小和横纵间距，也可铺满整页。
- 配对绑定稳定主机身份与公钥，IP 变化后重新发现并核验原身份。

产品系列名使用 **Desklet**，仓库名使用 `desklet`。电脑端对外名称为 **Desklet 连接助手**，移动端为 **Desklet 工作台**。应用标识、协议身份和配置目录保持不变。

## 运行开发版本

需要 Rust（1.89+）、Node.js（22+）、pnpm 11、Flutter 3.44 / Dart 3.12，以及对应平台构建工具。桌面目前在 macOS 验证；Android 最低版本为 Android 9（API 28）。依赖已提交锁文件。

```sh
make setup           # 安装桌面与 Flutter 依赖
make dev             # 打开 Desklet 连接助手，关闭窗口后仍在菜单栏运行
make android         # 在指定 Android 设备运行，先设置 ANDROID_DEVICE
make check           # 文档、格式、Rust 测试、桌面类型与 Flutter 检查
make android-build   # 生成开发 APK，不是签名发布版本
make prototype       # 保留原 HTML 布局原型预览
```

`make android ANDROID_DEVICE=<设备序列号>` 用于选择运行设备。Android 开发 APK 位于 `apps/android/build/app/outputs/flutter-apk/app-debug.apk`。

两端连接同一 Wi-Fi，在电脑上点击「连接设备」，再在 Android 的「Desklet 工作台」中扫码。没有摄像头时，复制完整邀请并在 Android 点击「粘贴邀请」；最后回到电脑允许连接。邀请两分钟过期，只能配对一台设备。电脑可随时移除已配对设备。配对后，在电脑的设备卡片中勾选「近期会话」「Codex 额度」「API 用量」「快捷入口」；需要点击打开时，再勾选「允许在电脑上打开」。新增设备从未共享开始，升级后的 API 用量共享默认关闭。

电脑端「快捷入口」以图标网格展示网页和本机应用，右键可编辑或删除，拖动可调整顺序（键盘可用 Alt + 左右方向键）；顺序自动保存并同步到手机。支持添加网页和选择本机应用，名称、类型和 PNG 图标同步到手机，地址与应用路径只留在电脑。应用选择时自动读取图标，也可手动更换；旧入口启动后自动补齐。修改打开目标后，旧版本请求不能执行，单独更换图标不影响动作版本。Codex 会话每五秒读取本机数据库，最多显示近期 40 个非归档主会话；只共享标题、项目名和状态，不发送消息正文。额度通过本机 Codex app-server 每两分钟读取，需要 Codex 已登录，也可在连接助手中手动刷新；缺少可用额度时明确提示。

在电脑端「设置 → API 用量来源」连接 Sub2API：填写 HTTPS 站点、邮箱、密码及与上游一致的统计时区，再在设备卡片开启「API 用量」。密码保存在系统钥匙串，访问令牌只在采集进程内存中；Android 仅接收费用、Token、TPM 与统计窗口。用量每分钟更新，失败保留上次值，限流按服务端要求等待；切换账号会清除旧账号值。

Android 正常使用时左右滑动切页、上下滚动内容，只展示无边框的紧凑内容。长按页面空白或非交互内容进入编辑；此时才显示页面管理和编辑工具，可添加重复组件、隐藏恢复，以及设置会话 / 图标尺寸、间距与来源。拖动组件标题移动位置，拖动左右和下边缘调整尺寸；重叠时其他组件自动让位，一次撤销可整体恢复。组件设置以可拖动的浮动窗口展示，表单内部滚动，画布保持完整尺寸以便预览；取消与完成始终保留。完成保存所有页面，取消恢复本轮全部修改；保存失败保留草稿供重试。横竖屏分别保存摆放，实例参数共用，旧配置迁移和损坏恢复均保留备份。

工作台默认沉浸显示，随设备旋转自动切换横竖屏；需要固定方向时，在编辑工具的「显示」中开启「锁定旋转」（默认关闭）。沉浸、方向锁定和主题在本机保存，隐藏所有组件后仍可长按空白进入设置。

工作台 App 退到后台时暂停连接，回到前台后重新同步。自动发现不可用时仍可扫码或粘贴邀请；访客网络隔离和防火墙仍可能阻止直连。启动遇到配置或钥匙串访问问题时会显示提示，处理后退出重开。

验证范围和可重复运行的跨端测试见 [tests/README.md](tests/README.md)。

## 目录

```text
apps/
  desktop/       Tauri + React / Rust Agent
  android/       Flutter + Kotlin 工作台
crates/
  host/          身份、设备许可、来源与动作校验
  lan/           TLS、认证、发现、采集调度与打开执行
protocol/        后续的版本化 Schema 与跨语言消息样例
docs/            设计、研究和单文件原型
tests/           跨端测试说明
release/         后续的打包、签名和更新配置
scripts/         文档检查与跨端测试脚本
```

技术栈沿用已确定的 Tauri、React、Rust、Flutter 和 Kotlin。桌面前端使用 pnpm；依赖版本由锁文件固定。单电脑来源、有限打开动作、多页编辑与本机保存已实现；物理设备完整验收与签名发布仍按开发计划推进。

## 开发约定

修改功能前阅读对应设计；行为发生变化时同步更新文档。实现范围以开发计划中的当前阶段为准。业务通信走 HTTPS / WSS，发现消息只提供地址线索。组件显示偏好不能更改配对授权或远程动作的执行电脑。
