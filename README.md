# DeskBar

DeskBar 把 Android 屏幕变成电脑旁的工作台。电脑安装 **DeskBar 连接助手**（Agent），Android 安装 **DeskBar 工作台**，通过局域网配对连接。目标是显示会话、额度与 API 用量，并打开已授权的会话和快捷入口。

**当前阶段：单电脑工作台。** 已支持加密配对、逐设备共享 Codex 会话 / 额度和 Sub2API 用量、网页 / 应用入口，以及手机点击回到电脑打开。电脑端可按设备组合多页与重复组件、编辑布局和显示参数，并实时预览；Android 接收布局，断线可查看上次布局和数据。双端默认使用铂银，支持独立保存墨黑主题。

短配对码依赖的 PAKE、多网卡与网络变化、物理设备适配、签名安装与发布仍在开发计划中。当前构建是开发版本。

## 产品范围

- 一个桌面安装包，加一个 Android 安装包；无需部署 Core、MQTT Broker 或独立服务器。
- 会话、额度、API 用量和快捷入口均作为可选组件，支持同类组件重复添加。
- 页面自由组合组件，左右横滑切页；每个实例独立设置位置、区域尺寸和显示参数。
- 顶部状态栏可配置名称、日期时间、连接状态、主题切换和设置入口；「添加横屏总览」可新建顶部状态栏、额度侧栏、两列会话和底部图标栏，之后各组件仍可单独调整。
- Session 卡片可调整目标宽高与间距；快捷入口可选择固定或自适应最大图标尺寸，配置行数、左对齐 / 居中对齐 / 均匀分布 / 右对齐及横纵间距，也可铺满整页。
- 配对绑定稳定主机身份与公钥，IP 变化后重新发现并核验原身份。

产品系列名使用 **DeskBar**，仓库名使用 `deskbar`。电脑端对外名称为 **DeskBar 连接助手**，移动端为 **DeskBar 工作台**。应用标识为 `app.deskbar.agent` 与 `app.deskbar.workbench`，连接邀请使用 `deskbar://pair`。

本次更名同步更新应用标识、存储名称与协议产品标识。旧开发版的配对、配置和凭据不会自动迁移；使用新版本时需更新双端并重新配对，重新设置共享内容、API 用量来源和工作台布局。

## 运行开发版本

需要 Rust（1.89+）、Node.js（22+）、pnpm 11、Flutter 3.44 / Dart 3.12，以及对应平台构建工具。桌面目前在 macOS 验证；Android 最低版本为 Android 9（API 28）。依赖已提交锁文件。

```sh
make setup           # 安装桌面与 Flutter 依赖
make dev             # 启动本机服务端与 DeskBar 连接助手
make android         # 在指定 Android 设备运行，先设置 ANDROID_DEVICE
make check           # 文档、格式、Rust 测试、桌面类型与 Flutter 检查
make android-build   # 生成开发 APK，不是签名发布版本
make android-release # 使用本机发布密钥生成签名 AAB
make prototype       # 保留原 HTML 布局原型预览
```

`make android ANDROID_DEVICE=<设备序列号>` 用于选择运行设备。Android 开发 APK 位于 `apps/android/build/app/outputs/flutter-apk/app-debug.apk`。

`make dev` 会构建工作台编辑器、启动桌面开发界面与 Rust Agent。手机所需的发现、配对和 HTTPS / WSS 服务集成在连接助手中，无需另开服务；启动后保持终端运行，关闭助手窗口后仍在菜单栏提供连接，Ctrl+C 停止开发进程。开发界面使用本机端口 `1432`，手机连接的 LAN 服务优先使用 `42831`。

两端连接同一 Wi-Fi，打开 Android 的「DeskBar 工作台」后会自动查找电脑；点击电脑名称，回到电脑允许一次即可完成配对。自动发现受网络限制时，再使用电脑上的备用二维码，或复制完整邀请到 Android 的「粘贴邀请」。自动发现邀请两分钟过期，只能配对一台设备。电脑可随时移除已配对设备。配对后，在电脑的设备卡片中勾选「近期会话」「Codex 额度」「API 用量」「快捷入口」；需要点击打开时，再勾选「允许在电脑上打开」。新增设备从未共享开始，升级后的 API 用量共享默认关闭。

电脑端「快捷入口」分别提供「添加应用」和「添加网址」。应用可多选、拖入或从「最近使用」点击添加，自动读取名称和图标，并跳过重复应用。新网址默认填入 `https://`，可获取网站名称和图标，也可手动填写。入口卡片双击在本机打开，右键编辑或删除，拖动调整顺序（键盘可用 Enter 打开、Alt + 左右方向键排序）；添加应用、删除和排序立即保存并同步，表单编辑通过「保存入口」应用。点击编辑弹窗中的图标可选择图片，也可将图片拖到图标上。名称、类型和 PNG 图标同步到手机，地址与应用路径只留在电脑；旧入口启动后自动补齐图标。最近使用目前支持 macOS，连接助手运行时记录应用启动和前台切换，最多保留 64 条、90 天，本机记录不共享给设备。修改打开目标后，旧版本请求不能执行，单独更换图标不影响动作版本。Codex 会话每五秒读取本机数据库，最多显示近期 40 个非归档主会话；只共享标题、项目名和状态，不发送消息正文。额度通过本机 Codex app-server 每两分钟读取，需要 Codex 已登录，也可在连接助手中手动刷新；缺少可用额度时明确提示。

在电脑端「设置 → API 用量来源」连接 Sub2API：填写 HTTPS 站点、邮箱、密码及与上游一致的统计时区，再在设备卡片开启「API 用量」。密码保存在当前用户的本机凭据文件，重启自动读取，访问令牌只在采集进程内存中；Android 仅接收费用、Token、TPM 与统计窗口。用量每分钟更新，失败保留上次值，限流按服务端要求等待；切换账号会清除旧账号值。

电脑端「屏幕编辑」以鼠标与键盘操作为主：左侧常驻页面与组件列表，中间显示设备画布，右侧编辑属性；设备旋转不改变面板位置，窄窗口可切换面板。点击画布或列表选中，拖动组件与边缘握柄调整布局，也可直接输入网格位置、尺寸及显示参数。顶部直接添加组件，页面可拖动排序，组件可一键隐藏或恢复。支持方向键微调、Delete 删除、⌘ / Ctrl + Z 撤销及 ⌘ / Ctrl + Shift + Z 或 Ctrl + Y 重做；输入框保留文字编辑操作。预览与 Android 共用渲染器，持续显示该设备获准共享的数据；电脑端保存每台设备最近一次尺寸，离线时继续按该尺寸编辑，默认跟随设备当前横竖屏，也可手动切换横屏或竖屏布局，不展示尺寸或字号信息，也可查看原始尺寸或开启布局调试。每次变更停止操作约 450ms 后自动更新本机布局并下发设备，完成只退出编辑；更新失败保留当前改动，并在后续变更或完成时重试。离线设备重连后接收最新布局。

Android 左右滑动切页、上下滚动内容。右上角「设置」或长按空白打开基础设置，仅提供主题、全屏显示、锁定旋转、重连和断开连接。默认全屏并自动旋转，基础偏好保存在设备；布局由电脑管理，不再读取或迁移 Android 旧版本的本机布局，更新双端后在电脑重新设置。

工作台 App 退到后台时暂停连接，回到前台后重新同步。自动发现会在未配对时定期重试；访客网络隔离和防火墙仍可能阻止直连，此时可扫码或粘贴备用邀请。启动遇到配置或本机凭据文件访问问题时会显示提示，处理后退出重开。

电脑端 TLS 私钥和 Sub2API 密码保存在应用数据目录的 `credentials/store.json`，与普通配置分开；macOS 路径为 `~/Library/Application Support/app.deskbar.agent/credentials/store.json`。文件不额外加密，macOS / Linux 将目录权限设为 `0700`、文件权限设为 `0600`。已有 DeskBar 安装首次升级会从钥匙串导入原身份和账号密码，可能需要授权；成功后启动和采集不再访问钥匙串，已配对设备无需重新配对。若拒绝导入 API 密码，在设置中重新填写即可；若无法读取原电脑身份，则保留现有配对并提示恢复，不自动换钥。旧钥匙串条目保留，程序不再更新它们。

验证范围和可重复运行的跨端测试见 [tests/README.md](tests/README.md)。

## 目录

```text
apps/
  desktop/       Tauri + React / Rust Agent
  android/       Flutter + Kotlin 工作台
crates/
  host/          身份、设备许可、来源与动作校验
  lan/           TLS、认证、发现、采集调度与打开执行
protocol/        后续的版本化 Schema 与跨语言消息样例
docs/            设计、研究和单文件原型
tests/           跨端测试说明
release/         发布、签名和更新配置
scripts/         文档检查与跨端测试脚本
```

技术栈沿用已确定的 Tauri、React、Rust、Flutter 和 Kotlin。桌面前端使用 pnpm；依赖版本由锁文件固定。单电脑来源、有限打开动作、电脑端多页编辑、预览与布局同步已实现；物理设备完整验收与签名发布仍按开发计划推进。

## 开发约定

修改功能前阅读对应设计；行为发生变化时同步更新文档。实现范围以开发计划中的当前阶段为准。业务通信走 HTTPS / WSS，发现消息只携带短时配对材料，仍需 TLS 公钥核验和电脑审批。组件显示偏好不能更改配对授权或远程动作的执行电脑。
