# HostRuntime

独立 Rust 模块，负责稳定 Host 身份、进程 epoch、设备审批、邀请过期、令牌摘要、撤权和最小快照。没有 Tauri、MQTT、网络或页面依赖。当前尚未接入来源采集与动作执行。

非敏感配置和授权摘要原子写入 YAML；磁盘锁阻止同一配置目录的重复进程。设备原始令牌仅在有效期内的待领取内存记录中存在，不写磁盘，不进入 UI 响应。

`cargo test -p desklet-host` 覆盖邀请失效、错误秘密、审批前后、请求重试、撤权、持久化与 epoch 变化。后续有限动作遵循 [协议草案](../../docs/protocol.md#动作语义)，当前快照能力为空。
