# HostRuntime

独立 Rust 模块，负责稳定 Host 身份、进程 epoch、设备审批、邀请过期、令牌摘要、逐设备快照裁剪及有限动作校验。没有 Tauri、MQTT 或页面依赖。`sources` 提供只读 Codex 会话与额度适配，`usage` 提供独立 Sub2API 采集器；来源调度与本机执行由 LAN 模块承载。

非敏感配置和授权摘要原子写入 YAML；磁盘锁阻止同一配置目录的重复进程。设备原始令牌仅在有效期内的待领取内存记录中存在，不写磁盘，不进入 UI 响应。

Sub2API 站点、邮箱与统计时区是电脑配置，密码由 LAN 模块写入系统钥匙串；采集器只在内存保存访问与刷新令牌。拒绝非 HTTPS 站点、重定向、凭据 URL 和超过 8 KiB 的上游响应；错误提示不包含上游正文或密码。费用采用十进制定点舍入到百万分之一；缺失或负值不会冒充零。

`cargo test -p deskbar-host` 覆盖身份、授权、持久化、命令去重、只读来源、API 设备隔离、费用精度、日历时区 / 夏令时、HTTP 登录 / 令牌续期 / 限流 / 响应上限。有限动作遵循 [协议草案](../../docs/protocol.md#动作语义)。
