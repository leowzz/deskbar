# LAN

嵌入桌面进程的 Rust 连接模块：HTTPS / WSS、固定 Host 公钥的邀请、设备凭据认证和 IPv4 query / offer。自动发现 offer 同时携带短时一次性配对邀请，Android 点击电脑名称即可发起请求；稳定身份与授权规则委托给 [HostRuntime](../host/README.md)，二维码仍作为发现失败时的备用入口。

TLS 私钥保存到应用数据目录的 `credentials/store.json`，证书可续签且 SPKI 不变。凭据文件不额外加密；macOS / Linux 使用 `0700` 目录与 `0600` 文件，临时文件写入、同步后原子替换。新安装不访问系统钥匙串；已有安装仅在首次导入时读取旧条目，之后完全使用本机文件。导入失败或文件损坏时不会为已有配对自动更换私钥。HTTPS 优先端口 42831，冲突时选择系统端口。发现使用实验组 `239.77.68.76:42831`，尚未冻结网络参数。多网卡、IPv6、接口变化重绑与局部扫描仍待实现 / 实测。

`cargo test -p deskbar-lan` 使用真实 TLS 请求验证受保护快照和撤权。专门的 Android 测试夹具默认忽略，不链接进生产应用；运行方式见 [跨端验证](../../tests/README.md)。

已实现 [协议草案](../../docs/protocol.md#v1-连接实现子集) 的连接与工作台子集：来源独立调度、授权快照和有限打开动作。Sub2API 密码按 Host 与站点 / 邮箱身份分开保存到本机凭据文件，先保存新凭据再原子提交配置，避免中途退出后旧网址读到新账号密码。正常切换成功后清理旧本机密码；账号修改立即清除旧值，丢弃在途旧账号响应，配置与凭据读取也受同一代校验。撤销共享立即裁剪快照。额度和用量分别响应手动刷新，上游限流期间保留旧值并等待重试。尚无图标资源接口。
